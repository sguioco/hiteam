# Delete User Appointment

Endpoint: DELETE /user/records/{record_id}/{record_hash}
Version: 1.0.0
Security: BearerPartner

## Path parameters:

  - `record_id` (number, required)
    Appointment ID (enough to delete the appointment if the user is authorized)
    Example: 22123

  - `record_hash` (string, required)
    HASH appointments (required to delete the appointment if the user is not authorized)
    Example: "'dawd4fs09rhf0s9fafef0'"

## Header parameters:

  - `Accept` (string, required)
    e.g. application/vnd.api.v2+json
    Example: "application/vnd.api.v2+json"

  - `Content-Type` (string, required)
    application/json

  - `Authorization` (string, required)
    Bearer partner_token, User user_token

## Response 401 fields (application/json):

  - `success` (boolean)
    Response status.

  - `data` (object,null)
    Response data.

  - `meta` (object)
    Additional response data.

  - `meta.message` (string)
    Error message.
    Example: "Authentication needed."
