# v4.fun launch watcher

Два backend-воркера:

- `v4fun-site` проверяет страницу раз в 500 мс, сравнивает HTTP/HTML/JS/API fingerprint и сразу пишет об изменениях в Telegram.
- `v4fun-api` читает атомарный снимок первого воркера, разбирает новые JS-бандлы, находит API/GraphQL/WebSocket и EVM-адреса, затем опрашивает только обнаруженные на самом `v4.fun` read-only GET endpoints.
- Общие Canopy/Agen feed, `InstantFactory` и `ProgrammableRegistry` намеренно не используются: воркер ждёт инфраструктуру, опубликованную именно `v4.fun`.

Состояние хранится в Docker volume `v4fun-data`, поэтому перезапуск не создаёт повторные уведомления. Health endpoints доступны только на VPS: `127.0.0.1:8111/ready` и `127.0.0.1:8112/ready`.

Это мониторинг и обнаружение токенов. Он не подписывает транзакции и не совершает покупку автоматически.
