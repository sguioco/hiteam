## Найденный тяжёлый путь

В 20-ю минуту каждого часа запускается runTaskAutomationForAllManagers. Его выборка использовала taskInclude, загружая всю историю действий, фото и checklist для всех открытых задач менеджера. Эти связи не используются triggerTaskReminder. На момент диагностики: 128 179 TaskActivity, 2636 активных задач, у крупнейшего менеджера 1837 задач с dueAt.

Одинаковые первые 20 задач одного менеджера (orderBy id asc), последовательные read-only запросы из отдельного Node-процесса на VPS:

| Выборка | Время | Размер сериализованных данных | Изменение RSS процесса |
|---|---:|---:|---:|
| taskInclude, старая | 139 мс | 1 621 905 байт | +23 445 504 байт |
| Только поля напоминаний | 3 мс | 7 704 байта | −3 117 056 байт |

Это разовые измерения, не p95 и не обещание ускорить весь API в такое же число раз. RSS зависит от сборки мусора; отрицательная дельта не означает отрицательную стоимость запроса. Полную старую выборку на production намеренно не воспроизводили, чтобы не вызвать новый OOM. Точный heap-профиль упавшего процесса недоступен, поэтому связь этой выборки с конкретным OOM остаётся обоснованной гипотезой.

Новая выборка всех 2627 активных задач с dueAt: 197 мс, 976 146 байт. Она больше не растёт вместе с историей действий.

## Изменения и проверка

- Убраны неиспользуемые relations из фоновых напоминаний; история остаётся доступной в карточках задач.

- Сетевые ошибки и timeout веб-запросов получают понятный текст. Автоматического повтора смены пароля нет: после потери ответа результат записи может быть неизвестен.
